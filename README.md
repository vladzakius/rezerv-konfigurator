# Конфігуратор резервного живлення

Веб-інструмент для монтажника: вводиш параметри об'єкта (інвертор, АКБ, ввід, траса, групи) — отримуєш:

- **кольорову схему щита** у стилі реальних апаратів (Schneider, Hager, Tomzn, ZUBR): L червоний, N синій, PE жовто-зелений, DC;
- **кошторис матеріалів** з автоматичним підбором номіналів (автомати, перемикач, ПЗВ, DC-автомат, кабель) + вартість монтажу в $ або грн;
- **список покупок** з чекбоксами;
- **PDF-фотозвіт для замовника**: обладнання, схема, виконані роботи, кошторис, фото;
- **підказки для монтажника** (ліміт АКБ, нулі TN-C, заряд, полярність DC).

Довідник цін і моделей редагується на сторінці. Бренд у моделі визначає вигляд апарата на схемі.

## Запуск

```bash
npm install
npm run dev              # локально
npm run build            # звичайна збірка в dist/
npm run build:artifact   # один самодостатній файл dist-artifact/index.html
```

## Збереження даних

- Поза claude.ai — чернетка і ціни зберігаються в `localStorage` браузера.
- У claude.ai Artifact — довідник цін і об'єкти зберігаються в сховищі артефакту (`db`), файли зберігаються через `downloads`.

## Структура

```
src/
  catalog.js     довідник за замовчуванням, зони кошторису, приклад об'єкта
  compute.js     розрахунок позицій, номіналів, підказок, список покупок
  scheme.js      генератор SVG-схеми
  report.js      PDF-фотозвіт (html2canvas + jsPDF)
  runtime.js     можливості claude.ai (db, downloads) з запасним варіантом
  components/    форма, панелі, звіт, довідник, об'єкти
```
